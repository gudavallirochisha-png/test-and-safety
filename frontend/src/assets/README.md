# Assets Folder (`frontend/src/assets`)

## Purpose
This folder stores static assets used across the presentation layer, including:
- SVG icons, logos, and vector illustrations.
- Enterprise branding graphics and platform logos.
- Static visual mock samples or placeholder assets.

## Architectural Guidelines
- Keep assets organized by domain subgroup (e.g., `icons/`, `images/`, `logos/`).
- Import SVGs directly as React components or standard image modules to leverage Vite asset optimization.
